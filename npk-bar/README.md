# npk-bar

A Claude Code mod: context window, session/week limits and progress estimates
above the prompt, toggled with `/npk-bar`.

Screenshots, installation and usage: see the README at the root of the
[npk-bar repository](https://github.com/victordomingos/npk-bar).

Quick reference:

| Command | What it does |
|---|---|
| `/npk-bar` | Turns it on or off, keeping the layout |
| `/npk-bar gauges` | Ring gauges (default in the desktop app) |
| `/npk-bar compact` | Short text bar (default in a terminal) |
| `/npk-bar full` | Full-width text bar with one bar per limit and estimate |
| `/npk-bar status` | What the mod sees right now, for reporting problems |
