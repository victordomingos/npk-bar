# npk-bar

This folder holds the npk-bar mod for Claude Code, which shows the context
window, your 5-hour and weekly usage limits, and the progress estimates just
above the prompt. You can turn it on and off with `/npk-bar`.

For screenshots, installation steps and a full explanation of the panel,
please see the README at the root of the
[npk-bar repository](https://github.com/victordomingos/npk-bar).

Quick reference:

| Command | What it does |
|---|---|
| `/npk-bar` | Turns the panel on or off, keeping the current layout |
| `/npk-bar gauges` | Ring gauges (the default in the desktop app) |
| `/npk-bar compact` | A short text bar (the default in a terminal) |
| `/npk-bar full` | A wider text panel, with a bar for each limit and estimate |
| `/npk-bar status` | Shows what the mod sees right now, for reporting problems |
