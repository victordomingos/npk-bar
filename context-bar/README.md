# context-bar

A Claude Code mod: context window, session/week limits and progress estimates
above the prompt, toggled with `/context-bar`.

Screenshots, installation and usage: see the [repository's README](../README.md).

Quick reference:

| Command | What it does |
|---|---|
| `/context-bar` | Turns it on or off, keeping the layout |
| `/context-bar gauges` | Ring gauges (default in the desktop app) |
| `/context-bar compact` | Short text bar (default in a terminal) |
| `/context-bar full` | Full-width text bar with one bar per limit and estimate |
| `/context-bar status` | What the mod sees right now, for reporting problems |
